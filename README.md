# 档案封面封底套打工具

本地离线运行的网页工具，用于在预印好的 A4 档案封面 / 封底纸质模板上精确套打填写内容，也可选择连底图一起打印生成完整页面。

## 一、打开方式

直接**双击 `index.html`** 即可在浏览器中打开使用（推荐 Chrome / Edge）。

- 无需安装任何软件或依赖
- 无需联网
- 底图已内置于 `assets/` 目录，工具运行不依赖原始 PDF

## 二、快速上手

1. 在顶部选择**录入方式**：单份（逐字段填写）或批量（粘贴表格）。
2. 点击**封面 / 封底**页签，分别在左侧录入对应字段，右侧实时预览。
3. 需要微调时，直接拖动预览中的字段；点选字段后按方向键可微调 0.1mm（按住 Shift 为 1mm）。
4. 展开字段下方的**位置/样式**，可直接输入 X、Y、宽、高的毫米值，以及字体、字号、对齐、是否显示。
5. 选择**打印模式**：
   - **套打**：隐藏底图，只打印文字，适用于预印好的实体纸张；
   - **完整**：底图与文字一起打印，直接得到完整页面。
6. 点击**一键打印**可直接调起打印对话框（按当前页签与录入内容生成打印页，无需先打开预览）；或点**打印预览**查看效果后再打印，也可点**预览两页**一次性左右并排输出封面 + 封底。预览窗口内可用 **− / ＋ / 适应** 调整缩放。
7. 若套打整体偏上 / 偏下、偏左 / 偏右（打印机进纸偏差），点**页面设置**调整「打印整体偏移」，所有字段统一平移，预览实时生效。
8. 若个别字段位置不对，可点**重置位置**恢复默认布局。

## 二·五、字体

工具在 `fonts/` 目录内置公文风格字体（无需系统安装），**全部为免费可商用的开源字体**（SIL Open Font License 1.1），可放心用于单位/商业场景：

| 字体文件 | 字体名称 | 风格/用途 | 许可证 |
| --- | --- | --- | --- |
| sourcehan_heavy.otf | 思源宋体 Heavy | 标题（替代方正小标宋） | SIL OFL 1.1（Adobe/Google） |
| sourcehan_bold.otf | 思源宋体 Bold | 标题备选（替代方正大标宋） | SIL OFL 1.1（Adobe/Google） |
| sourcehan_sans.otf | 思源黑体 | 数字（替代系统黑体） | SIL OFL 1.1（Adobe/Google） |
| zhuque_fangsong.ttf | 朱雀仿宋 | 正文（替代仿宋_GB2312） | SIL OFL 1.1（TrionesType） |
| lxgw_wenkai.ttf | 霞鹜文楷 | 楷体风格（替代楷体_GB2312） | SIL OFL 1.1（lxgw） |

**默认字体规范**：单位名称、类别、案卷题名用**思源宋体 Heavy 20pt**；起止年月日、件数、页数、保管期限、全宗号、目录号、案卷号等数字类字段用**思源黑体 14pt**；其余文字字段（卷内摘要、封底说明、立卷人等）用**朱雀仿宋 14pt**。

> 注：旧版本内置的方正小标宋/仿宋_GB2312 等字体商业使用需授权，已全部移除并替换为上述开源字体。已保存的旧配置会自动回退到新默认字体。

每个字段都可以单独修改：展开该字段的**位置/样式**，在「字体」下拉框中选择（另提供宋体系统字体选项），字号范围 6–48pt。修改立即生效并自动保存。

## 三、打印设置（重要）

为保证套打定位准确，打印对话框中请设置：

| 项目 | 设置值 |
| --- | --- |
| 纸张大小 | A4（210 × 297 mm） |
| 缩放 | 100%（不要选"适合页面"） |
| 页边距 | 无 |
| 页眉页脚 | 关闭 |
| 背景图形 | 完整模式建议开启（确保底图输出） |

工具内部已使用 `@page { size: A4; margin: 0 }`，字段均为毫米绝对定位，预览与打印保持一致。

**页面设置（打印整体偏移）**：点击顶部工具栏的**页面设置**，可设置水平 / 垂直偏移（毫米，范围 ±30，精度 0.1）。这是针对打印机进纸误差的整体校准——例如套打内容统一偏左 1mm，则把水平偏移设为 +1 后所有字段一起右移 1mm，无需逐个拖动字段。偏移保存在本机，打印预览实时体现。

## 四、批量录入

**方式一：粘贴表格**。从 Excel 选中表格区域复制，粘贴到批量模式的文本框中，点击**解析表格**。

**方式二：导入文件**。点击**导入文件**，支持 `.csv`、`.xls`、`.xlsx`（Excel 解析组件已内置，离线可用；CSV 自动识别 UTF-8 / GBK 编码）。

**方式三：下载模板**。点击**下载模板**可获得带表头和示例行的 `档案套打批量模板.xlsx`（未加载 Excel 组件时自动降级为 CSV 模板），填入数据后通过导入文件或粘贴解析。

表头支持以下列名（中文名或字段名 id 均可，忽略空格）：

- 封面：单位名称、类别、案卷题名、卷内摘要、起年、起月、日起、止年、止月、止日、件数、页数、保管期限、全宗号、目录号、案卷号
- 封底：本卷情况说明、立卷人、检查人、立卷时间

也支持复合列：

- `起止时间`：如 `2024年3月5日起至2025年6月8日止`，自动拆分为起年/起月/日起/止年/止月/止日
- `立卷时间`：如 `2024年3月5日`，自动填入封底立卷时间

点击**复制表头模板**可获得一行标准 TSV 表头，粘贴到 Excel 第一行即可。

解析后可用**上一条 / 下一条**逐条预览，或直接**批量打印全部**（每条记录输出封面 + 封底两页）。

## 五、数据管理

- 字段位置、单份数据、批量记录及界面设置均自动保存在浏览器 `localStorage`，刷新不丢失。
- **导出JSON**：把布局与全部数据保存为一个 JSON 文件。
- **导入JSON**：从 JSON 文件恢复（会覆盖当前数据，导入前请确认）。

## 七、已知限制

- 默认字段位置按内置扫描底图校准；若使用不同版本的纸质模板，需手动调整字段位置并可在布局面板中精确输入毫米值。
- 浏览器打印对话框的设置不会由网页强制修改，首次打印请按上文第三节手动确认。
- 数据保存在当前浏览器中，更换浏览器或清理浏览数据前请先导出 JSON。
- 批量粘贴解析适用于常规表格；含引号内换行的复杂 CSV 已支持，但极端不规范文本可能需要手工整理。
