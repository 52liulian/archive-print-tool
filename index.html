打印整体偏移：当套打内容整体偏上 / 偏下、偏左 / 偏右时，在此设置统一平移量（毫米）， 所有字段同时移动，无需逐个拖拽。正值方向：X 向右、Y 向下。打印预览会实时体现偏移效果。

纸张固定为 A4（210 × 297mm）、页边距 0（@page 已内置，浏览器打印对话框请保持 100% 缩放、无边距）。打印模式（套打 / 完整）在顶部工具栏切换。

使用说明

  1. 套打模式：只打印填写的文字，不打印底图。请将预印好的档案封面/封底纸张放入打印机，按预览位置套打。
  2. 完整模式：底图与文字一起打印，可直接生成完整封面页。打印对话框请勾选「背景图形」以确保底图输出。
  3. 精确定位：默认位置依据底图实测换算，一般无需调整。若纸张放置有偏差，可拖动字段或展开「位置/样式」直接输入毫米数值；坐标精度 0.1mm。
  4. 打印设置：纸张 A4、缩放 100%、页边距「无」。工具已使用 @page { size: A4; margin: 0 }，请勿在浏览器中再次设置缩放。
  5. 字体：单位名称、类别、案卷题名默认思源宋体 Heavy 20pt，起止年月日、件数、页数、保管期限、全宗号、目录号、案卷号等数字类字段默认仿宋_GB2312 14pt，其余文字字段默认朱雀仿宋 14pt（fonts 目录内置字体，无需系统安装；仿宋_GB2312 等传统公文字体商业使用需自行确认授权）。展开字段「位置/样式」中的「字体」下拉框可单独更换，数字字段也可选朱雀仿宋、思源黑体等开源字体。
  6. 打印预览：默认整页完整显示在当前屏幕内（多页左右并排）；可用 − / ＋ 缩放、点「适应」恢复完整显示。
  7. 页面设置：套打整体偏上/偏下、偏左/偏右时，设置「打印整体偏移」统一平移所有字段。
  8. 批量录入：表头可用字段中文名（单位名称、类别、案卷题名、卷内摘要、起年、起月……）。也支持「起止时间」「立卷时间」复合列。
  9. 数据管理：字段位置、单份数据、批量记录均自动保存在本机浏览器。可导出/导入 JSON 档案在多台电脑间迁移。
